# Assets locales

La esfera, las órbitas, las estrellas, la marca y los efectos de luz se dibujan con CSS/SVG. La intro se anima con GSAP y las interacciones con Motion. No necesitan un servicio externo al abrir la app.

Las fotografías de ejemplo se descargaron de Unsplash y se guardaron en `public/images/`. El script `scripts/download-assets.mjs` conserva sus URLs para reproducir la descarga:
